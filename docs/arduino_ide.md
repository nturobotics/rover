# drive
1. copy and paste [arduino_drive.cpp](https://github.com/nturobotics/rover/blob/main/scripts/arduino_drive.cpp) file
2. change wifi and password to the wifi you want to use
3. connect your laptop and any device you want to use to control the **Rover** to that wifi
4. press **File > Save All**
5. upload
6. open serial monitor **(plug icon)**
7. copy the server link http://{wifi_id} to browser
8. unplug the ESP32-CAM and connect to **Rover**
9. put batteries in (some wheels will autorun for a bit, it's normal)
10. control the **Rover** with your phone or laptop
11. [guide](https://lastminuteengineers.com/getting-started-with-esp32-cam/)
